# Kaia photo stickers

Drop photo files here to show cute circular stickers on the meal-plan page.

## File names

Use these exact names (PNG recommended):

- `kaia-1.png`
- `kaia-2.png`
- `kaia-3.png`

You can add more later by extending the sticker `<img>` tags in `index.html`.

## Tips

- Square crops work best (the page shows them as circles).
- Keep files reasonably small for GitHub Pages (under ~500 KB each is plenty).
- Missing photos are fine — the page hides broken images and falls back to a strawberry SVG so nothing looks broken.

## Example

```
assets/kaia/
  README.md          ← you are here
  kaia-1.png         ← add me!
  kaia-2.png
  kaia-3.png
```

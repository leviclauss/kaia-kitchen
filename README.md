# Kaia's Nom Nom Week

A cute funny static weekly meal-plan for 13-month-old Kaia. Strawberries and corgis theme. Soft pinks reds cream. Mobile friendly.

## Enable GitHub Pages

1. Push this folder's contents to a GitHub repo (as the repo root, or put these files at the root of main).
2. Open the repo on GitHub - Settings - Pages.
3. Under Build and deployment:
   - Source: Deploy from a branch
   - Branch: main (or your default branch)
   - Folder: / (root)
4. Click Save. After a minute or two, the site URL appears on the same Pages settings screen (usually https://USERNAME.github.io/REPO/).

No Actions workflow required for the classic Deploy from a branch option.

## Add Kaia photos

1. Place photos in assets/kaia/ named kaia-1.png, kaia-2.png, kaia-3.png.
2. See assets/kaia/README.md for details.
3. Missing files will not break the page - stickers hide on error and a strawberry fallback shows instead.

## Local preview

Open index.html in a browser, or serve the folder with any static file server, then visit http://localhost:8080

## Files

- index.html - Main page (meals + day pills + sticker logic)

- assets/corgi.svg - Cute corgi illustration
- assets/strawberry.svg - Cute strawberry illustration
- assets/favicon.svg - Tab icon

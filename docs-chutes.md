# AI week generation (Chutes)

Ad-hoc week plans are generated by the Supabase Edge Function `generate-week`, which calls the Chutes OpenAI-compatible API (`https://llm.chutes.ai/v1/chat/completions`). The API key **never** goes in the browser.

## 1. Get a Chutes API key

1. Sign up / log in at Chutes and create an API key.
2. Optional: pick a model for `CHUTES_MODEL`. Code default: `deepseek-ai/DeepSeek-V3` (override e.g. `Qwen/Qwen3-235B-A22B` if available).

## 2. Set function secrets (required)

Project ref: `wdkimbxxaweysweooavs`

```bash
supabase link --project-ref wdkimbxxaweysweooavs
supabase secrets set CHUTES_API_KEY=YOUR_CHUTES_KEY
supabase secrets set CHUTES_MODEL=deepseek-ai/DeepSeek-V3
```

Dashboard: **Project Settings → Edge Functions → Secrets**. Add `CHUTES_API_KEY` and optionally `CHUTES_MODEL`.

`SUPABASE_URL` / service role / anon keys are injected automatically into Edge Functions.

## 3. Deploy

```bash
supabase functions deploy generate-week --project-ref wdkimbxxaweysweooavs
```

Source: `supabase/functions/generate-week/index.ts`.

## 4. Use in the app

On **Week planner**, open **Generate week**, set the **From the book ↔ Try new** slider (default ~60% from the book), generate, edit the draft, optionally save new recipes to the book, then **Apply to this week**.

Frontend: `supabase.functions.invoke('generate-week', { body: { existingRatio, weekStart } })`.
